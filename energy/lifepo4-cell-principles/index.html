锂离子电芯：
工作原理与典型异常机制

以磷酸铁锂正极与石墨负极体系为例，系统说明充放电中的 Li⁺ 与电子传输，并梳理析锂、自放电和内短路等异常问题的形成机理、可观测线索与判读边界。

说明：动画仅表达方向和过程，不代表真实微观轨迹、粒子速度或析锂形貌；电解液不传输自由电子，隔膜阻止两极直接接触。

充电时：Li⁺ 去石墨负极

充电器把电子送到石墨负极；与此同时，Li⁺ 从正极脱出，穿过电解液和隔膜进入石墨层间。两个过程共同维持电荷平衡。

电极反应（理想化）

正极：LiFePO₄ → FePO₄ + Li⁺ + e⁻负极：6C + Li⁺ + e⁻ → LiC₆

LiC₆ 是充分嵌锂石墨的理想化组成；实际锂含量随 SOC 变化。

要记住的重点

Li⁺ 走电解液，e⁻ 走外电路。 正常充电时锂被储存在石墨层间，并不会先变成金属锂再进入石墨。

02 · 正常嵌锂与异常析锂，究竟差在哪？

正常反应

嵌锂（Intercalation）

Li⁺ + e⁻ + 6C → LiC₆
  • 锂进入石墨层间的嵌入位点。
  • 是电芯设计中的正常充电储能过程。
  • 仍受到温度、动力学、SOC 等条件影响。
不希望发生的副反应

析锂（Lithium plating）

Li⁺ + e⁻ → Li(s)
  • 锂在负极表面形成金属锂沉积。
  • 可能导致活性锂损失、界面副反应和容量衰减。
  • 部分沉积可能是不规则形态，增加隔膜受损、内短路风险；并非每次析锂都形成枝晶。

04 · 为什么析锂能从电压曲线中看出一些蛛丝马迹？

01 / 充电过程

Q–V 曲线

锂的嵌入、极化以及可能的副反应，都会影响电压随累计充电容量的变化。异常平台本身不等于析锂。

02 / 微分特征

dQ/dV、dV/dQ

通过曲线斜率和容量增量放大细微变化。不同阶段的新峰或峰位变化可能提供线索，但很容易受到噪声和温度影响。

03 / 充电后静置

电压弛豫

正常充电停止后电压通常逐渐回落；部分析锂相关反应会使弛豫曲线出现额外平台或斜率特征，需与正常基线对比。

跟二阶 RC 模型有什么关系？

二阶 RC 模型用两个时间常数近似描述正常极化动态：Vₜ = OCV − IR₀ − U₁ − U₂（约定放电电流为正）。充电停止后，模型可以描述常规极化电压的逐渐消退。若实测弛豫明显偏离同工况下的正常参考，可能提示存在额外过程；但残差异常不能单独证明析锂，也可能来自温度、SOC、滞回和模型失配。

05 · 对你的储能 EMS，哪些功能现阶段可做？

第一步 · 当前可做

基于单体温度、簇 SOC 和充电电流，记录低温、大倍率、高 SOC 的风险工况与持续时间。

第二步 · 需要验证

用簇级约 8 秒一轮的电压、电流寻找充电后静置片段，研究较慢的电压弛豫特征。

第三步 · 数据增强

单体约 60 秒一次的数据可初探 Q–V；高质量 dQ/dV、dV/dQ 需要验证采样精度、时间同步和电流工况。

第四步 · 实验标定

与电芯厂或实验室合作，获取已验证析锂样本，建立风险判据、误报控制和诊断可信度。

最后用三句话记住

充电：Li⁺ 从 LiFePO₄ 正极去石墨负极，电子通过外电路到负极，锂正常嵌入石墨。

放电：Li⁺ 从石墨负极回到正极，电子通过外部负载流向正极，对外输出电能。

析锂：充电时部分 Li⁺ 没有正常嵌入石墨，而是获得电子变成金属锂沉积在负极表面；它会带来老化和潜在安全风险。
