01 · 从结果认识问题

我们到底想算什么？

假设电池静置时测到 3.80 V，现在突然让它以 10 A 放电：电池端电压不是始终不变，而是先突然下降，然后缓慢下降。停电流后，又会先突然回升，再缓慢恢复。

一阶 RC 模型的第一个任务：给定电流，预测电池端电压随时间变化的曲线。在 SOC 估算中，还可以用“预测电压与实测电压的差”辅助修正 SOC。

全程采用约定：放电电流 I 为正，先用单体电芯、恒温以及短时间内 OCV 近似不变的例子学习。

02 · 先解决你提过的疑问

一阶 RC 到底是串联还是并联？

你之前发过的电路是经典 RC 低通滤波器：串联一个 R，输出端接一个对地的 C。这当然属于一阶 RC 系统。

电子电路中的 RC 低通

\[RC\frac{dV_o}{dt}+V_o=V_i\]

BMS 中的一阶极化支路

\[R_1C_1\frac{dU_1}{dt}+U_1=IR_1\]

它们的数学形式都是一阶微分方程，因此都有指数式的变化。区别在于：前者用输入电压驱动，后者的极化支路用电池电流驱动。

03 · 对照整个电池模型

OCV、R₀、R₁、C₁、U₁ 到底在哪？

🔵 OCV：平衡开路电压🟠 R₀：欧姆内阻🟢 U₁：并联支路两端极化电压

整个电路按放电方向看，电池的基础电压 OCV 要减去两个压降：欧姆压降 IR₀ 和 极化压降 U₁。

\[\boxed{V_t=OCV(SOC)-IR_0-U_1}\]
别混淆：U₁ 是电压（单位 V），而 R₁ 是电阻（单位 Ω）。公式里减的是 U₁，不是 R₁。R₁、C₁ 决定 U₁ 随时间怎样变化。
04 · 从最基础的电学定律开始

为什么 I = U₁/R₁ + C₁·dU₁/dt？

把电流 I 想象成一条河流，它流到并联支路的分叉口后，分成两路：一路流过电阻 R₁，一路流过电容 C₁。

总电流 = 两条支路电流之和（KCL）

\[I=I_R+I_C\]

电阻上的电流：欧姆定律

并联意味着 R₁ 和 C₁ 两端电压相同，都是 U₁。

\[I_R=\frac{U_1}{R_1}\]

电容上的电流：电压变化得越快，电流越大

\[I_C=C_1\frac{dU_1}{dt}\]

其中 \(dU_1/dt\) 的意思是“此刻 U₁ 每秒变化多少伏”。它不是 U₁ 除以时间，而是瞬时变化率。

举例：如果 C₁ = 100 F，电压每秒上升 0.1 V，那么电容电流就是 100 × 0.1 = 10 A。

将两条支路电流相加

\[\boxed{I=\frac{U_1}{R_1}+C_1\frac{dU_1}{dt}}\]

注意符号方向：我们把流入并联支路、使 U₁ 增大的方向定义为正。因此当 U₁ 在下降时，电容电流可能是负值。

05 · 数学推导，不跳步骤

指数函数 e 到底是怎么来的？

这部分要推导的目标是：

\[\boxed{U_1(t)=IR_1\left(1-e^{-t/(R_1C_1)}\right)}\]

该式有两个前提：① 电流 I 在这一段时间内恒定；② 开始时极化电压 U₁(0)=0。

把电容电流留在左边

\[C_1\frac{dU_1}{dt}=I-\frac{U_1}{R_1}\]

同除以 C₁，整理成：

\[\frac{dU_1}{dt}=\frac{IR_1-U_1}{R_1C_1}\]

分离变量

左边只留下 U₁，右边留下时间 t：

\[\frac{dU_1}{IR_1-U_1}=\frac{dt}{R_1C_1}\]

两边积分

\[\int\frac{dU_1}{IR_1-U_1}=\int\frac{dt}{R_1C_1}\]

为什么左边有负号？因为分母 \(IR_1-U_1\) 对 U₁ 求导等于 −1。

\[-\ln|IR_1-U_1|=\frac{t}{R_1C_1}+K\]

从自然对数 ln 变成指数 e

ln 和 \(e^x\) 是反函数。将常数整理后，可以写成：

\[IR_1-U_1=Ae^{-t/(R_1C_1)}\]

于是：

\[U_1=IR_1-Ae^{-t/(R_1C_1)}\]

利用初始条件确定 A

从充分静置开始，U₁(0)=0。把 t=0 代入，并注意 \(e^0=1\)：

\[0=IR_1-A \quad\Longrightarrow\quad A=IR_1\]

代回上一步，提取公共因子 IR₁：

\[\boxed{U_1(t)=IR_1\left(1-e^{-t/(R_1C_1)}\right)}\]
一句话解释 e：由于极化电压变化的快慢，取决于它离最终值 \(IR_1\) 还有多远，因此会出现“先快后慢”的指数变化。

更一般的情况：开始时 U₁ 不为零

\[\boxed{U_1(t)=IR_1+\big[U_1(0)-IR_1\big]e^{-t/(R_1C_1)}}\]

把 U₁(0)=0 放进去，就回到刚才推导的特殊公式。若停电流 I=0，就得到：

\[\boxed{U_1(t)=U_1(0)e^{-t/(R_1C_1)}}\]

这解释了停止放电后，极化电压逐渐消失、端电压缓慢恢复的现象。

07 · 从数学走向 BMS 软件

怎样让 MCU 每 100 ms 算一次？

微分方程使用的是连续时间 t，而 MCU 每隔 Δt 执行一次计算。若每个采样周期内电流近似恒定，就能把一般解变成离散递推式。

\[U_1[k+1]=a\,U_1[k]+R_1(1-a)I[k]\]
\[\boxed{a=e^{-\Delta t/(R_1C_1)}}\]

再配合安时积分更新 SOC，并查 OCV-SOC 表，就能计算端电压：

\[\boxed{\hat V_t[k]=OCV(SOC[k])-I[k]R_0-U_1[k]}\]

下面的代码演示一种先用当前时刻的状态预测端电压，再推进到下一时刻的更新顺序，避免时间索引混乱。

// 放电电流为正，以下参数仅示例
float R0 = 0.010f;     // ohm
float R1 = 0.020f;     // ohm
float C1 = 2000.0f;    // F
float dt = 0.100f;     // s
float U1 = 0.0f;       // 初始极化电压

// 参数不变时，a 可以提前算好
float a = expf(-dt / (R1 * C1));

// 每次调用，输入这一采样时刻的电流 I，单位 A
float predict_voltage(float I, float SOC)
{
    float ocv = ocv_lookup(SOC); // 真实项目用标定表

    // 当前状态对应的电压预测
    float Vt = ocv - I * R0 - U1;

    // 推进极化状态到下一采样时刻
    U1 = a * U1 + R1 * (1.0f - a) * I;

    return Vt;
}

这里的 ocv_lookup() 是示意接口，需要你自己实现。SOC 可以先用安时积分更新，再保证预测电压和 U₁ 的索引与采样电流一致。

到这里，一阶 RC 模型能做的是电压预测。再把预测电压和 ADC 实测电压比较，才进入 EKF 等 SOC 状态校正算法。
08 · 学完检查一下

3 道题，看看是否真的理解

问题 1：在 BMS 一阶 Thevenin 模型中，U₁ 指什么？
正确答案是 B。R₁、C₁ 是模型参数，U₁ 才是极化压降。

问题 2：如果 I=0，且 U₁ 初始不为零，会发生什么？
正确答案是 A。因为 \(U_1(t)=U_1(0)e^{-t/(R_1C_1)}\)。

问题 3：R₁ 固定，C₁ 变大，电压动态响应会怎样？
正确答案是 C。因为 τ=R₁C₁ 增大，达到相同变化比例需要更长时间。

最后只记住三条公式

\[\boxed{V_t=OCV(SOC)-IR_0-U_1}\]
\[\boxed{\frac{dU_1}{dt}=-\frac{U_1}{R_1C_1}+\frac{I}{C_1}}\]
\[\boxed{U_1[k+1]=aU_1[k]+R_1(1-a)I[k]}\]
